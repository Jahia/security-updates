# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| Latest 1.0.x release | Yes |
| Anything older, and snapshots | No |

The module requires Jahia 8.2.3.7 or later. Only the latest release receives fixes.

## Scope

In scope: this module (the Java code, the GraphQL API, the admin page and the banner, the default
configuration). Out of scope: vulnerabilities of Jahia itself, of the Jahia Store, or of a third-party store
or feed (report them to their owners).

## Reporting a Vulnerability

Security information can be found in our [security.txt file](https://academy.jahia.com/.well-known/security.txt).
Do not open a public issue for a vulnerability.
